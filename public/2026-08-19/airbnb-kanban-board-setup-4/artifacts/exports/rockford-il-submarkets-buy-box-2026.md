# Rockford, IL — submarkets, live screens, and buy box for 1–4 unit investing (2026)

## Bottom line
Rockford stays a **selective TAKE**, but the next-layer view is narrower:

- **Best stabilized 1–4 unit submarkets:** **61107**, **61114**, **61108**
- **Best value-add / higher-upside but higher-friction submarkets:** **61103**, **61104**
- **Deep-discount only / heavier management risk:** **61101** and weaker pockets elsewhere

For a cash-flow buyer, the sweet spot is **small residential rentals in better east / northeast corridors** and **distressed duplex–fourplex opportunities where the basis is low enough to absorb rehab**.

## Rockford 2026 acquisition buy box

### A. Stabilized SFR buy box
| Metric | Target |
|---|---|
| Preferred ZIPs | **61107**, selective **61108**, selective **61114** |
| Target all-in basis | **≤ $100K** on ordinary long-term-rental deals |
| Stretch all-in basis | **$100K–$125K** only with above-average condition or stronger rent support |
| Target monthly rent | **$1,250–$1,600+** |
| Target gross yield | **11%+** |
| Rehab budget | **light-to-moderate** preferred |
| Avoid | heavy foundation, major sewer, full gut, or block-level obsolescence |

### B. Duplex buy box
| Metric | Target |
|---|---|
| Preferred ZIPs | **61104**, **61103**, selective **61107** |
| Target all-in basis | **≤ $190K** |
| Stretch all-in basis | **$190K–$220K** only with strong layout, separated utilities, and low capex |
| Target rent per unit | **$850–$1,100+** |
| Target gross yield | **12.5%+** |
| Rehab posture | cosmetic + mechanical cleanup is fine; avoid structural mystery projects |

### C. 3–4 unit buy box
| Metric | Target |
|---|---|
| Preferred ZIPs | **61103**, **61104**, selective **61101** only at deep discount |
| Target all-in basis | **3-unit: ≤ $265,950** / **4-unit: ≤ $330,960** |
| Better target | **well below those ceilings**, especially on 1900-era buildings |
| Target rent per unit | **$850–$1,100+** |
| Target gross yield | **13%–14%+** |
| Non-negotiables | rent roll, utility setup, code status, roof/mechanicals, turnover budget |

### Why these thresholds
Using the city’s **$985** monthly median gross rent as a baseline, the following rough basis ceilings fall out of a disciplined Rockford cash-flow model:

| Property type | Baseline annual rent proxy | Max all-in basis used in this screen | Implied gross yield |
|---|---:|---:|---:|
| 1-unit | $11,820 | **$100,470** | **11.8%** |
| 2-unit | $23,640 | **$189,120** | **12.5%** |
| 3-unit | $35,460 | **$265,950** | **13.3%** |
| 4-unit | $47,280 | **$330,960** | **14.3%** |

These are **screening thresholds**, not final underwriting. Better ZIPs can justify rent premiums; worse blocks require bigger discounts.

## What to buy vs. what to avoid in Rockford

### Best fits
1. **Tenant-ready SFRs under $100K–$125K all-in** in stronger east-side pockets
2. **Brick duplexes** with separated utilities and manageable cosmetic rehab
3. **4-unit buildings** with low per-unit basis and verifiable rent upside
4. **Infill-adjacent value-add deals** supported by the city’s housing investment push

### Avoid
1. Retail-priced houses in better ZIPs that do not pencil as rentals
2. 1900-era 3–4 units without utility clarity or capex visibility
3. Any deal where the neighborhood thesis is just “cheap”
4. Deep west-side acquisitions without management infrastructure and collections discipline
