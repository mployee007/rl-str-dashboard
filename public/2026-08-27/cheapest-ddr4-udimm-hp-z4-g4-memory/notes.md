# Notes — Cheapest DDR4 UDIMM for HP Z4 G4 Memory

## User Context
- User wants the cheapest 256GB DDR4 UDIMM kit that fits an HP Z4 G4.
- User is open to new or used.

## Key Findings
- Kingston compatibility page snippet for HP/HPE Workstation Z4 G4 (Xeon): up to 256GB on Xeon W-2100 using 8/16/32GB modules in groups of four; up to 512GB on Xeon W-2200 using 8/16/32/64GB modules in groups of four.
- Kingston KSM26ED8/32ME datasheet confirms 32GB DDR4-2666 CL19 288-pin DIMM, ECC, dual-rank module.
- Newegg page for Kingston KSM26ED8/32ME showed $50.00.
- Newegg page for A-Tech compatible 32GB ECC UDIMM replacement showed $50.00.
- eBay product page for Samsung M391A4G43MB1-CTD showed a used listing at $240.00 with free shipping.

## Observations
- Current accessible used eBay listing is materially more expensive than the cheapest accessible new Newegg options.
- Generic search results were noisy; direct page fetches and browser extraction were more reliable.
