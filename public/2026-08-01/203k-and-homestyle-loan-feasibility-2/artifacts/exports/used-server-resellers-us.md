# US Used Server Resellers — Shortlist

## Verdict
If you want companies that clearly specialize in used/refurbished enterprise hardware in the US, start with **ServerMonkey, TechMikeNY, The Server Store, UNIXSurplus, and IT Creations**. They all explicitly market refurbished or used servers and related enterprise gear. **XByte** is worth considering as a larger enterprise supplier, but the site blocked direct extraction during this run, so its entry below is based on Bing search snippets rather than direct page text.
