# R&L Collective — Co-Host Onboarding Checklist & SOP Bundle

## 1. Owner onboarding checklist
- signed management agreement
- owner contact details
- emergency contact details
- property address and unit access details
- STR permit/registration status verified
- HOA/building rules reviewed
- insurance confirmed
- payout flow confirmed
- pricing goals and blackout dates confirmed
- supply and restock expectations confirmed

## 2. Property setup checklist
- smart lock / keypad configured
- wifi tested and documented
- thermostat instructions documented
- parking instructions documented
- house rules confirmed
- safety items verified (smoke detector, CO detector, extinguisher, first aid)
- cleaner access process documented
- maintenance contacts loaded
- photo inventory / condition baseline completed

## 3. Listing setup checklist
- title drafted
- description written
- amenity list completed
- house rules entered
- check-in/check-out instructions set
- registration/permit number added if required
- photos uploaded and sequenced
- pricing baseline set
- minimum stay / cleaning / pet settings reviewed

## 4. Guest messaging SOP
### Booking confirmation
- thank guest
- confirm dates and guest count
- restate key house rules
- set expectation for check-in message timing

### Pre-check-in (24 hours before)
- send access instructions
- parking instructions
- wifi info if appropriate
- check-in reminder
- support contact method

### Mid-stay message
- ask if everything is going smoothly
- invite issue reporting early

### Checkout message
- simple checkout steps
- thank guest
- review request follow-up

## 5. Turnover SOP
- cleaner notified immediately at booking and again before checkout
- post-checkout inspection completed
- photos taken for damage/issues
- linens reset
- toiletries/restock checked
- trash handled
- thermostat/lights/windows checked
- property marked ready

## 6. Issue escalation SOP
### Minor issue
- acknowledge within 15–30 minutes
- offer immediate workaround
- dispatch vendor if needed
- update owner if cost threshold is triggered

### Major issue
- guest safety first
- owner notified immediately
- vendor dispatched
- Airbnb contacted if platform support needed
- incident log recorded

## 7. Monthly owner reporting template
Include:
- occupancy
- ADR
- RevPAR
- gross revenue
- refunds/adjustments
- cleaning/variable costs
- management fee
- net owner payout
- review score
- notable issues and action items

## 8. Minimum standards / SLAs
- inquiry response target: under 15 minutes during active hours
- guest issue response target: under 30 minutes
- turnover confirmation before each arrival
- owner report delivered monthly

## 9. Non-negotiables
- no listing taken on without compliance review
- no single-cleaner dependency
- no vague fee agreements
- no mixed personal/business spending
